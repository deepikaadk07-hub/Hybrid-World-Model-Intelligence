# Hybrid World Model Intelligence Framework

## Project Overview

This project integrates computer vision, object tracking, and Vision-Language Models for real-time decision support.

The system uses YOLOv8 for object detection, ByteTrack for object tracking, and BLIP for scene understanding. A world model maintains scene information, while a decision engine identifies potential risks in restricted zones.

## Technologies Used

- Python
- YOLOv8
- ByteTrack
- BLIP
- OpenCV
- PyTorch
- COCO Dataset

## Installation

1. Clone the repository.
2. Create a virtual environment using `python -m venv venv`.
3. Activate it using `venv\Scripts\activate`.
4. Install dependencies using `pip install -r requirements.txt`.

## Execution

Run the application:

`python main.py`

Press Q to quit the application.

## Dataset

COCO (Common Objects in Context)

Official website: https://cocodataset.org/

## Project Features

- Real-time object detection
- Object tracking using ByteTrack
- Vision-language scene understanding
- World-state management
- Restricted-zone monitoring
- Risk classification
